# VLSI-Design-Internship-Task-3
VLSI Design Internship Task 3 – Sequential Circuits, Flip-Flops, Registers, Counters &amp; Verilog RTL Design.

This repository contains my work for **Task 3 of the VLSI Design Internship**, focused on designing and implementing sequential digital circuits using **Verilog HDL**.

## 📌 Topics Covered

* Sequential Logic Circuits
* D Flip-Flop
* JK Flip-Flop
* 4-Bit Register
* Counters
* Verilog RTL Coding
* Testbench Development
* Simulation and Waveform Analysis

## 🛠️ Tools & Technologies

* Verilog HDL
* RTL Design
* Digital Logic Design
* Simulation & Waveform Analysis
* Vivado / Verilog Simulator

## 🎯 Objective

The objective of this task is to understand the working of sequential circuits and implement them using Verilog HDL. The designs are verified through testbenches and simulation waveforms.

## 🔬 Implementation & Verification

Each circuit includes its Verilog RTL implementation and, where applicable, a corresponding testbench. The simulation waveforms are analyzed to verify the expected functionality of the designs.

## 📊 Results

The implemented sequential circuits were simulated and their output waveforms were analyzed to verify their expected behavior.

The detailed internship report is available in the `Report` folder.

## 📚 Learning Outcome

Through this task, I strengthened my understanding of **sequential logic, flip-flops, registers, counters, Verilog RTL coding, testbench development, and simulation-based verification**.
